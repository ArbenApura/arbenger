### Problem

Students needed a free alternative to paid grammar-checking apps (e.g. Grammarly) — the existing tools hide most features behind premium upgrades.

### Solution

"Top One Uwu" — a free AI-powered writing and study assistant web app for students. Started as an exploration of SvelteKit, it grew into a suite of tools and caught national media attention. By combining free tiers of Supabase, OpenAI, and Render, the whole site could run for free.

### Key Features

- Grammar fixer
- Content rephraser
- Content expander
- Content summarizer
- Essay writer
- Essay title generator
- Plagiarism checker

### Tech Stack

- SvelteKit
- Supabase (database)
- OpenAI API
- Tailwind CSS
- Render (hosting)
