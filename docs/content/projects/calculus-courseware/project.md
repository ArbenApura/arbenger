### Problem

A client (completing a Doctoral Degree program) needed a courseware platform specifically tailored to Basic Calculus, covering the full teaching workflow: from enrolled students through lessons, materials, and assessments.

### Solution

A comprehensive web application for managing a Basic Calculus course — built to handle the entire learning process for the client's doctoral program. A courseware platform with student and teacher accounts, where teachers manage courses and lessons.

### Key Features

- Student and teacher accounts
- Teachers manage courses and lessons
- Video materials
- Module delivery
- Interactive worksheets
- Assessments
- Manage enrolled students
- Track academic quarters

### Tech Stack

- Next.js
- React
- Firebase (backend + database)
