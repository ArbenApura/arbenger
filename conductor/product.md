# Product Definition — Arbenger

## Project Name

Arbenger

## Description

Arbenger.com is the company hub for Arbenger, a tech company building and shipping products across multiple platforms: VS Code extensions, Chrome plugins, AI tools, browser-based utilities, and SaaS products. The website serves as both a showcase/portfolio and a commercial landing page, with live free tools (image resizer, image compressor) that run entirely in the browser.

## Problem Statement

No single place to discover, showcase, and drive users to Arbenger's products across multiple platforms. Users need a central hub to explore what Arbenger builds, and a destination for free, privacy-first utility tools.

## Target Users

- **Developers** discovering Arbenger products (VS Code extensions, Chrome plugins, AI tools)
- **General web users** needing free online image processing tools (resizer, compressor, background remover)
- **Potential customers** evaluating Arbenger's SaaS products

## Key Goals

1. **Ship polished base site + establish brand identity** — Dark futuristic "terminal meets luxury" aesthetic, distinctive and memorable
2. **Build scalable foundation for new products** — Architecture supports adding new tools, product pages, and features incrementally
3. **Excellent SEO and Core Web Vitals from day one** — Pre-rendered pages, self-hosted fonts, edge-deployed on Cloudflare
