# Specification: Live HTML Preview Editor

**Track ID:** html-editor_20260525
**Type:** Feature
**Created:** 2026-05-25
**Status:** Draft

## Summary

A privacy-first, client-side HTML/CSS/JS editor with live preview, Prettier formatting, CodeMirror 6 syntax highlighting, inline error detection (Error Lens style), responsive multi-device preview, Emmet support, built-in console, offline PWA support, and export capabilities. Fills the market gap between dead-simple editors (W3Schools TryIt) and overkill IDEs (CodeSandbox/StackBlitz).

## Context

Arbenger builds free, privacy-first browser utilities (Image Resizer, Image Compressor). This product extends the portfolio into developer tools — a natural fit for the brand's "100% private and free" promise. Research shows the online editor market is bifurcated: simple editors lack formatting/linting/offline, while full IDEs are overkill for HTML/CSS/JS work. Top user complaints include paywalled privacy, no Prettier integration, no inline error detection, poor mobile experience, and no offline support.

## User Story

As a web developer, I want to quickly test HTML/CSS/JS snippets with live preview so that I can prototype and debug without setting up a local environment.

## Acceptance Criteria

- [ ] Three-pane editor (HTML/CSS/JS) with CodeMirror 6 syntax highlighting
- [ ] Live preview updates as user types (with debounce, pausable)
- [ ] Prettier format-on-click for all three languages (HTML, CSS, JS)
- [ ] Inline error detection (HTMLHint, ESLint Linter, CSSTree) with Error Lens-style display
- [ ] Emmet abbreviation expansion in HTML and CSS panes
- [ ] Responsive preview with device presets (mobile, tablet, desktop)
- [ ] Built-in console capturing console.log/warn/error/info and runtime errors
- [ ] Export as ZIP (separate files) or standalone HTML file (single file with inlined CSS/JS)
- [ ] 100% client-side — no server processing, no signup, no data leaves browser
- [ ] Offline PWA support after first visit (Service Worker + IndexedDB)

- Template/starter gallery (future enhancement)

## Technical Notes

- **CodeMirror 6 over Monaco** — 300KB core vs 5-10MB, mobile-first design, superior accessibility, modular tree-shaking
- **Prettier standalone ESM** — Runs fully in browser via `prettier/esm/standalone.mjs` with parser plugins, no Node.js needed
- **iframe sandbox** — Preview runs in sandboxed iframe with `srcdoc`, isolating user code from host page
- **Console capture** — Override `console.*` methods inside iframe, post messages to parent for display
- **Error Lens pattern** — CodeMirror `@codemirror/lint` decorations API for inline error/warning text at line ends
- **Web Worker for linting** — Run HTMLHint/CSSTree/ESLint off main thread to prevent UI jank
- **PWA** — Service Worker caches editor assets; IndexedDB stores user's last session (code state)
- **Route** — `/products/html-editor` under `(utilities)` group route
- **Layout** — Flexible panel layout: editor panes (resizable) + preview + console, with toolbar above
