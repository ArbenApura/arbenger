# Specification: Sound Booster Chrome Extension

**Track ID:** `sound-booster-ext_20260519`
**Type:** Feature
**Created:** 2026-05-19
**Status:** Draft

## Summary

Chrome extension that amplifies audio beyond 100% using Web Audio API, with per-tab volume control, multi-band equalizer, presets, and keyboard shortcuts. Follows same vanilla TypeScript + esbuild + Manifest V3 architecture as color-picker extension.

## Context

Arbenger builds and ships products across multiple platforms including Chrome extensions. The color-picker extension established the architecture pattern: vanilla TypeScript, esbuild bundling, Manifest V3, minimal permissions, privacy-first design, dark/light theming. Sound Booster is the second Chrome extension in the Arbenger product line.

## User Story

As a media consumer, I want to boost quiet audio beyond browser limits so that I can hear low-volume videos/streams without external software.

## Acceptance Criteria

- [ ] Audio volume amplifiable up to 600% on any tab
- [ ] Per-tab independent volume controls
- [ ] Audio equalizer with frequency band adjustment (bass, mid, treble+)
- [ ] Built-in presets (Music, Movie, Voice/Podcast, Bass Boost, etc.)
- [ ] Custom preset save/load
- [ ] Volume level persisted per-tab across popup open/close
- [ ] Keyboard shortcuts for quick volume up/down
- [ ] Visual volume indicator / peak meter
- [ ] Same architecture as color-picker (vanilla TS, esbuild, Manifest V3)
- [ ] Minimal permissions — no unnecessary page access

## Dependencies

None. Standalone extension, reuses only build patterns from color-picker.

## Out of Scope

- No audio recording/capture/download features
- No cross-tab audio mixing or routing
- No microphone input processing
- No integration with external audio software (Spotify, system mixer)
- No DRM-protected audio manipulation (Netflix, Disney+ — Web Audio API can't access)
- No website-specific auto-rules
- No mobile/Firefox/Safari — Chrome only

## Technical Notes

- **Web Audio API** — `AudioContext` + `GainNode` for volume boost, `BiquadFilterNode` for EQ bands
- **Content script** — injects into pages to intercept `<audio>`/`<video>` elements, routes through audio processing graph
- **Permissions**: `activeTab`, `storage`, `scripting` (inject content script on demand)
- **Dark/light theme** matching color-picker design language
- **Same build pipeline** — esbuild, TypeScript, generate-icons, package scripts
