## Full Description

Pick any color from any webpage — the HEX value copies to your clipboard instantly.

Color Picker gives you the tools designers and developers actually need, without the permissions they shouldn't have to grant.

WHAT YOU GET:

• One-click eyedropper — Click any pixel, HEX auto-copies to clipboard
• Four output formats — HEX, RGB, HSL, OKLCH. Click any row to copy
• Two-color contrast checker — Set text + background, see WCAG AA/AAA pass or fail
• Color blindness simulation — Protanopia, deuteranopia, tritanopia preview (Machado 2009 algorithm)
• Color harmonies — Complementary, analogous, triadic, split-complementary palettes
• Shades & tints — 9-step lighter-to-darker ramp from any picked color
• Persistent history — Last 10 picks saved across sessions
• Light & dark mode — Toggle in the popup header

WHY THIS ONE:

Most color picker extensions request "access to all websites" — meaning they can read every page you visit. Multiple popular extensions have been caught injecting tracking code after being sold to new owners.

This extension uses only two permissions:
• activeTab — lets the eyedropper read the pixel you click (nothing else)
• storage — saves your color history and settings locally

No page content access. No network requests. No analytics. Under 20 KB total.

BUILT FOR DEVELOPERS:

• OKLCH output for perceptually uniform color adjustments
• WCAG 2.1 contrast ratios with AA, AA+ (large text), and AAA badges
• Color blindness simulation using the same Machado 2009 algorithm as Chrome DevTools
• Manifest V3 — the latest and most secure Chrome extension platform

Free. No account needed. No data collected.
